# Cumulative-Returns-vs.-Volatility
A Python data visualization tool using yfinance, matplotlib, and seaborn to track and compare financial performance. It calculates the close-to-close cumulative returns (growth of $1) for AAPL, MSFT, and SPY over a 5-year window, alongside the 30-day annualized rolling volatility of the S&amp;P 500 to map asset growth against market risk.
